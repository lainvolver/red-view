# RedView — r/anime コメントランキング & トレンド分析ダッシュボード

Reddit のアニメコミュニティ [`r/anime`](https://www.reddit.com/r/anime/) に投稿される各話ディスカッションスレッドのコメント数を AniList の作品メタデータと紐づけ、シーズンごとの盛り上がりや推移を比較・分析するための Web ダッシュボードです。

GitHub Actions によって日々データが自動収集・更新され、Astro でビルドされた静的サイトとして GitHub Pages にデプロイされます。

---

## 主な機能

- **ランキング一覧**: 最新話・前話・累計・平均・最高話・急上昇（前話比）の各指標で作品ランキングを表示。順位変動バッジ、前話比、話数推移のインラインスパークライン、作品名検索、Rewatch スレッド除外フィルタに対応しています。
- **複数作品の比較チャート**: ランキングや検索から最大 8 作品を選び、折れ線推移・累積コメント推移・指標比較棒グラフで並べて比較できます。X 軸基準（話数 / 収録順 / 最新話基準）や線形・対数スケールの切り替えも可能です。
- **順位推移（バンプチャート）**: シーズン内の順位変動をインタラクティブな折れ線グラフで可視化。凡例のホバーやクリック（ピン留め）で特定作品の推移だけを強調表示できます。
- **傾向分析（インサイト）**:
  - **熱量 × 勢いポジショニングマップ**: 平均コメント数（基礎人気）と最新話の対平均比（勢い）の散布図から、覇権作や神回による急上昇作を一目で把握できます。
  - **コメントシェア構成・分布・急上昇・維持率**: 上位作品の集中度、コメント規模帯の分布、前話比急上昇トップ、第 1 話からのコメント維持率ランキングを表示します。
  - **全シーズン横断比較**: 過去シーズンを含む総コメント数と 1 話あたり平均コメント数の推移を比較できます。
- **作品詳細モーダル**: 作品名やグラフ要素をクリックすると、全話コメント数の推移グラフ（平均ライン付き）と各話 Reddit スレッドへのリンク一覧を確認できます。
- **ダーク / ライトテーマ切替**: ヘッダーのトグルボタンでテーマを切り替えられます。

## ローカル確認方法

### 前提環境

- **Node.js** 22 以上（推奨）および **npm**

### 1. 開発サーバーで確認する

```bash
cd astro
npm install
npm run dev
```

起動後、ブラウザで以下の URL を開いてください。

> **注意**: `astro/astro.config.mjs` で `base: "/red-view/"` が設定されているため、URL 末尾に `/red-view/` が必要です。

- **アクセス URL**: `http://localhost:4321/red-view/`

### 2. 本番ビルドをプレビューする

```bash
cd astro
npm run build
npm run preview
```

同じく `http://localhost:4321/red-view/` にアクセスして、本番ビルド後の表示・データ読み込みを確認できます。

### 3. シーズン一覧ファイル（`seasons.json`）の再生成

`data/reddit/` に新しいシーズン JSON を追加・更新した場合は、リポジトリルートで以下を実行して `astro/public/data/reddit/seasons.json` を更新します。

```bash
node tools/generate-seasons.mjs
```

## リポジトリ構成

```text
.
├── .github/workflows/       # データ取得・更新・GitHub Pages デプロイ用ワークフロー
├── astro/                   # Astro フロントエンド本体
│   ├── public/data/reddit/  # 配信用のシーズン別 JSON・seasons.json
│   └── src/
│       ├── pages/           # トップページ (index.astro)
│       ├── scripts/         # 集計・グラフ描画・UI制御 (TypeScript)
│       └── styles/          # ダッシュボード用スタイル (CSS)
├── data/                    # 収集生データおよびシーズン別アーカイブ JSON
├── scripts/                 # AniList / Reddit API 取得・マッチング用 Python スクリプト
└── tools/                   # seasons.json 生成スクリプト (generate-seasons.mjs)
```
